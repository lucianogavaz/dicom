# DICOM Gateway Frontend

Pasta reservada para a interface web do projeto.

## Papel do Frontend

O frontend nao se comunica diretamente com o equipamento DICOM. Ele serve para operacao e monitoramento do sistema.

## Funcoes Previstas

- dashboard operacional
- visualizacao da fila
- consulta de estudos recebidos
- cadastro de destinos PACS
- reenvio manual
- visualizacao de logs e falhas

## Stack Sugerido

- `Next.js`
- `React`
- `TypeScript`

## Status Atual

O frontend ainda nao foi implementado. Esta pasta ja esta preparada para receber o projeto web quando a camada backend estiver validada.
